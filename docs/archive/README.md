# Archived engagement narratives

retained for context. Files in this directory are dated and reflect
the state at the time of writing; they are not maintained against
the live repository state. For current state see the parent
[`README.md`](../../README.md), the per crate `CHANGELOG.md` files,
the [`docs/decisions/README.md`](../decisions/README.md) ADR index,
and the live ADR set under `docs/decisions/`.
