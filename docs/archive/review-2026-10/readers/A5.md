### A5-1 evidence
Reproducer: scratchpad/A5/probe; `printf 'd128 sinh 14150.05\n' | target-A5/release/drv`. Output vs mpmath: d128 sinh(14150) = 9.244617257381687763023063770892394E+6144 (correct); d128 sinh(14150.01) = Infinity (mpmath 9.3375e6144); d128 cosh(14150.07) = Infinity (mpmath 9.9149e6144); d64 sinh(887.1) = Infinity (mpmath 9.1539e384); d32 sinh(224.01) = Infinity (mpmath 9.6667e96); `d128 sinh 14150.05` → Infinity#20 Infinity#20 9.99…9E+6144#20 Infinity#20 9.99…9E+6144#20; `d32 sinh -224.04` → −Infinity#20 −Infinity#20 −9.999999E+96#20 −9.999999E+96#20 −Infinity#20. Oracle: mpmath 60 to 130 dps rounded per mode with CPython decimal at the format's precision, range and clamp (py/check.py). Thresholds: true ln(2·MAX) is d128 14150.07854, d64 887.18841, d32 224.04390; the gates are 14150, 887, 224. Extent: exhaustive at d32 (d32band.txt): all 439 positive sinh inputs and all 439 negative cosh inputs from ±224.0001 to ±224.0439 are wrong in all 5 modes (4,390 of 4,390 cells), doubled by the other sign; ~1.9e12 inputs per sign per function at d64, ~7.9e27 at d128. Trace: hyperbolic.rs:161 `x_ext`; :172 `abs > exp_overflow_limit()` → `saturate_overflow` → `round_and_pack_finite(pre_sticky=true)`; the comment at :162-165 assumes the exp gate's premise, which `(e^x − e^-x)/2` does not satisfy for a width of ln 2. Why missed: S2 swept exactly this band (sample.rs:177) but `production_ne` flags an infinite result as nonnormal (sample.rs:361) and `evaluate` returns `NonNormal` before the mirror (sweep.rs:121); the frozen corpora have no sinh row above 14133.44 and sinh/cosh are NE-only (C1-5); `transcend_directed` pins exp gates but no hyperbolic gate; property_hyperbolic's oracle is one sided and never draws near the gate.

### A5-2 evidence
`printf 'd128 exp -14221.3\nd128 pow 10 -6176.3\n' | drv` → `0E-6176#56 0E-6176#56 0E-6176#56 1E-6176#24 0E-6176#56` for both. Truth (mpmath): exp(-14221.1) = 7.157e-6177, exp2(-20517) = 5.856e-6177, exp10(-6176.3) = 5.012e-6177, all above 5e-6177, so NE/NA must deliver `1E-6176`; ln(5e-6177) = −14221.45868. Controls: exp(-14221.46) is correctly 0; exp(-14220.9) is correctly `1E-6176`. Root cause: format_impl.rs:150 derives the boundary as "≈ −14220.85" (ln 2 added with the wrong sign; true −14220.766 − 0.693 = −14221.459). Siblings safe: d64 gate 918 vs true −917.122, d32 gate 235 vs −233.254. Why missed: S2's d128 exp negative band and exp2 band cover the window but zero results are discarded (A5-7); `transcend_directed::exp_underflow_directed_modes` pins a point past the true boundary.

### A5-3 evidence and the class closure
`printf 'd128 atan2pi 1E-6141 1E-6176\n' | drv` panics in all 5 modes. Trace: gap 35 < P+2 = 36 so the anchor at inverse_trig_pi.rs:499 does not fire; :519 → inverse_trig.rs:544 `y.div::<F>(x)` → extended.rs:781 `to_format(1E-6176)` → `recip_seed` = +∞ → extended.rs:168 panic. The d128 panic region is `|x| < 1/MAX` with `adj(y) − adj(x) ≤ 35`. Class closure: `from_format` of a format datum and the constant deliveries are total; the only computed values that cross the format are the Newton seeds in `Extended{,2,Dyn}::{recip, sqrt}`; in-scope callers whose operand can leave the range are asinh and acosh (`sqrt(x² ± 1)`), atan2 and atan2_pi (`recip(x)`), and `atan_extended_core` stage 1 (`recip(q)` with q > MAX silently returns 0, harmless). The tan, tanh, atanh, asin and acos divisors are bounded; sincospi is protected by its quantum floor. Fix that closes the whole class: in the three Newton primitives, scale the operand to `[1,10)` (recip) or by an even power of ten into `[1,100)` (sqrt), then re-apply the shift (exactly `pow.rs::working_reciprocal`); removes all five panics, the silent zero, and the subnormal-seed precision loss at zero budget cost. Kernel dispatch is an optional optimization that alone would leave the trap for the next caller.

## Design notes
1. Let the Newton primitives own their range (scale internally or take an operand type carrying the invariant); `powi`'s `working_reciprocal` is already the third caller to need it.
2. A gate table, (function, format) → (overflow T, underflow T, derivation), with one test against mpmath `ln(k·MAX)`; today gates borrow `exp`'s constant and its comment.
3. Strata aimed at gates must certify saturated outputs rather than discard them.
4. One shared NaN-and-zero special dispatcher with per-function rows layered on top (removes A5-4, A5-5 and the C2-2/C2-3 class; `powr` already gets both rows right).
5. A standing mutation harness (about 15 minutes per function; separate target directory per mutant).
