### Evidence (condensed)

C5-1: reproducer `scratchpad/C5/repro_panic/` (catch_unwind): d64 asinh(1E190) ok, 1E193/1E200/-1E200/7E247/1E384 PANICKED; d32 asinh(1E48) ok, 1E50/-1E60/7E69/9E96 PANICKED; d128 asinh(1E3072) ok, 1E3073/1E3100/1E6000 PANICKED. Every panic: "from_format requires a finite or zero datum; NaN / Inf are dispatched at the public-API boundary" (extended.rs:168). Trace: asinh wrapper → ladder::run → asinh_kernel_body (hyperbolic.rs:378, `x_sq_plus_one.sqrt::<F>()`) → Extended::sqrt (extended.rs:817: `to_format::<F>` overflows to Inf; `sqrt_seed(Inf)` returns Inf) → from_format expect. libFuzzer found the first crashes in under 15 s. Why the stack missed it: the fuzz `transcendentals` target exists for exactly this contract and has been unbuildable since d87ae0a; no lane runs fuzz; the frozen corpora pin values only; Kani covers only special-value dispatch.

C5-2: d128 atan2(1E-6000, 1E-6100) ok; panics: atan2(1.58455116102709060557914701823E-6147, 4.61168882725010014976E-6156), atan2(1E-6150, 1E-6160), atan2(1E-6170, 1E-6176), atan2(1, 1E-6176), atan2(1E6144, 1E-6176). Trace: atan2 wrapper → atan2_kernel_body (inverse_trig.rs:416) → atan2_extended_core (:544, `y.div::<F>(x)`) → Extended::div → Extended::recip (:781-783: to_format then recip_seed produces Inf) → from_format panics. Siblings not run.

C5-3: `cargo metadata --no-deps --manifest-path fuzz/Cargo.toml` fails "current package believes it's in a workspace when it's not"; same for d64, d32, and `cargo +nightly fuzz build parse` (nightly 1.97.0, cargo-fuzz 0.13.1). Targets landed db4ed83 (2026-05-06); the root became a workspace at d87ae0a (2026-05-09). Scratch copies with absolute path deps and `[workspace]` build; 15 s smoke: all non-transcendental targets clean; all three transcendentals targets crashed.

C5-4/C5-5: `scratchpad/C5/ci_only.sh` ran every CI selection with no battery counterpart: all 19 pass on macOS at the baseline; `cargo test -p ferrodec-decimal32 --all-features` and `cargo test -p ferrodec-campaign` (run by no instrument) pass. No upstream, no PR, `gh run list --branch review-2026-10` empty; last five main CI runs failed; verification green 5 weeks but exercises neither ci.yml's selections nor the ubuntu-only package jobs.

## Design notes
1. One selection source feeding both the battery and CI, or a test that diffs them.
2. Generators take `--out` so a read-only regenerate-and-diff is possible.
3. Shard identity as a type: hash every Config field and a build id into the stream key and header; resume refuses a mismatch.
4. `Extended::{sqrt, recip}` should seed from a rescaled operand, not through `to_format`; that removes the whole Inf-then-panic class.
5. Validate sweep CLI combinations up front with an enum of valid shard kinds.
