## Found clean
Instrument: a copy of ferrodec-transcend/src with a test module `a1_probe.rs` implementing the copy's `DecimalFormat` for wrappers W128/W64/W32 by forwarding to the real formats, so `pub(crate)` classifiers run against the shipped rounders. Oracle `oracle2.py` + `check2.py`: true values by integer arithmetic from the definitions; rounding and flags by CPython decimal at `prec=P, Emax, Emin, clamp=1`; a tie means ROUND_HALF_UP ≠ ROUND_HALF_DOWN. Validated on planted errors first. Results: 339,012 direct classifier calls, zero wrong Some, zero wrong value or flag, zero missed exact or tie; 217,084 public API cases default build, no panic, every rational value matched, every irrational carried INEXACT; 21,334 negative-base odd-exponent API cases (for_negation) zero mismatches; ~107,300 API cases under `--cfg force_escalate --cfg force_adjudicate`, no `Equal` panic, no mismatch (no exact boundary input reaches the adjudicator). Families covered: width-gate edges and one past; ties at P+1 digits for exp2, exp2m1, pow, powi, rootn, rsqrt, compound, hypot (genuine ties confirmed in NE); trailing-zero cohorts and negative exponents; subnormal results incl. the constructed subnormal tie `x³ = 12.5E-6176`; results beyond emax and below etiny; the pow boundary with b up to 6000; compound at n = ±196, ±197, nines at both exponent ends; hypot `m²−1, 2m` and `k²+1` families; rootn at n = 2..39, 64, 100, 112, 113, 127, 128, 200, 1000, 3000, 6000, 2^31−1; rsqrt at `4^i`, `25^j`, `q²` reciprocals; log2p1/log10p1 nines at the digit limit; the pi residue edges. Blind spots: cohort and CLAMPED; inputs outside the generated structure; kernel correctness on non-boundary values (only INEXACT checked).

## Design notes
1. An in-tree real-format adapter would close C1-11 and C1-13 (the forwarding wrapper took ~60 lines).
2. The `2^α 5^β t → (coef, w)` assembly appears four times (pow, powi, rootn, integer_power_parts) with identical 127/55 gates; one shared function would retire C1-35's hard-coded constants.
3. `pack_value`'s precondition is prose only; a `debug_assert!` would document intent.
4. On the `Equal` panic: across 339k direct and ~107k force-adjudicate calls no exact or tie input escaped classification; supports the coordinator's posture without making it urgent.
