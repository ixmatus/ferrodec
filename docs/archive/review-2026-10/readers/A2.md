#### A2-3 evidence

Derivation. With `q = min(qw, qz)`, `A = |w|/10^q`, `B = |z|/10^q`, `|z| ≤ |w|` so `B ≤ A`. If `q = qw`, `A = cw < 10^P`. If `q = qz`, `|w| < 10^(adj_w+1)` and `qz = adj_z − digits_z + 1 ≥ adj_w − δ₀ − P + 1` (kernel band, hypot.rs:246), so `A < 10^(δ₀+P)`. Hence `S = A² + B² < 2·10^(2δ₀+2P)`: Decimal128 2·10^104, Decimal64 2·10^50, Decimal32 2·10^24. The documented bounds (`A < 10^(δ₀+2P−1)`, exact.rs:2733-2737, 2753-2755; `S < 2·10^170`, adjudicate.rs:57; `S < 10^174`, ADR-0060) count `digits_w` and the shift independently although they trade off. Consequence: Engine B's floor `1/(8.1·S)` ≥ 6.2e-106 at Decimal128, above rung 2's 250 unit threshold (≈ 2.5e-108) by ×240, so hypot.rs:118-123 ("possible only where `S` outgrows the floor's margin, `S ≳ 10^105`") describes an empty set.

Corroboration: default-build telemetry over the 51,855-call edge probe (`$A2/edge`, `telemetry` feature): 635 rung 2 entries, 0 adjudications in any operation; `hypot(1E-3072, 1E-3088)` (the `k²+1` shape, 1.25e-65 from a grid point) is decided by rung 2 itself, correctly in all five modes.

### Design notes

1. **Derive the Newton step count from the seed width** (as `extended_dyn::newton_steps` does). Then the rsqrt polish becomes a provable no-op at every format (or can go), and `HYPOT`/`POWI_INT`/`RSQRT` itemizations become true without per-format caveats. Evidence that would make it a finding beyond A2-2: any Decimal32 input within 1e-25 of a boundary in a Newton-using kernel outside this group (A3/A5 territory).
2. **Special rows should return a value plus a preferred quantum, not a finished `F`.** One shared "exact pack" (hypot's `pack_exact`) used by every §9.2.1 row would make A2-1 unrepresentable. Evidence: A2-1.
3. **`hypot_side` and `rsqrt_side` are production-dead by their floors** (×240 and ×120 margins at Decimal128); keeping them is cheap insurance, but the rustdoc should say they are reached only under `force_adjudicate`, and a telemetry pin should hold that count at zero, so a future budget loosening that starts routing through them is visible. Evidence: A2-3 telemetry.
4. **The `Equal` panic** (adjudicate.rs:114-124): I agree with Phase 1b's lean. Under `debug_assertions`/`ladder_audit` panic; in release deliver `b` itself through the format rounder with `pre_sticky = false` (a grid `b` is exact and gets no INEXACT; a midpoint `b` rounds by the mode's tie rule), which needs `Side` to grow an `On` arm and `deliver_at_boundary` to stop OR-ing INEXACT unconditionally. Evidence for a finding: a classifier gap reaching it from the public API (none found).
5. **Decider tests use only the 7-digit mock boundary.** The `force_adjudicate` lane over the edge probe is a ready-made per-format test for the extreme-exponent and subnormal brackets the C1 trust table lists as unseen; promoting `$A2/edge`'s operand set into the lane would close that blind spot. Evidence: none wrong found; the blind spot is the point.
