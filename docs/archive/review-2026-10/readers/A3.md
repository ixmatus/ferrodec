### A3-3 derivation
Per call: rung 2 delivers unconditionally in default builds, a 34 digit result drops 76 digits; each field of 10^76 units holds one grid point and one midpoint, so the band has measure 4·B₂ per 10^76 → ≈ 4·B₂·10^-76 per call (4e-72 for sin, 1.2e-67 for pow), also the probability of entering rung 3. README:266 and ladder.rs:1726 ("~10^-36 per call") are off by 31 to 35 orders in the safe direction. Per unary domain (~1e38 values): 4e-34 (sin) to 4e-30 (cbrt); the ADR's 10^-36 corresponds to B₂ ≈ 100, below every catalog rung 2 budget (smallest 250). Binary: pow has N ≈ 1e38 × 3.8e35 ≈ 1e74 pairs with in-range results not hugging 1 → expected count ≈ 1e7 at the budget, ≈ 400 with an actual rung 2 error of 1e4 units; atan2 ~1e72 distinct ratios → ≈ 10 at the budget. One-form statement: expected exceptions per unary function over its domain ≤ 4·B₂·10^-38; for pow, powr, atan2 and atan2_pi the count is not small.

## Found clean
Escalation predicate (`boundary_verdict`, both rungs): 13,593 constructed cases against an independent model (libmpdec rounding of the two bracket endpoints in all five modes, comparing value plus INEXACT, UNDERFLOW, OVERFLOW; A3/predcheck.py): tails at B and B+1 from each boundary family on both sides, deep subnormals, both sides of 10^E_MIN, the Nmax and 10^(Emax+1) edges, the all nines coefficient, a zero working value, 1 digit and 55 digit coefficients; 0 mismatches; 10^(Emax+1) is a genuine boundary (the OVERFLOW flag changes under round toward zero). Blind spot: positive values only; budgets ≥ field/4 untested. Margin arithmetic at normal width: margin.rs, the generator's `directed_margin`/`tie_margin` on the 50 digit lattice, and the predicate's distances at excess = 50 − P are the same function (derived algebraically); d64 and non-trig labels match Arb to 0.2%. campaign_certify value path rejects wrong-side values; `_decisive`'s straddle test is sound. certify_anchor_floor.py: side requires the ball to exclude zero; the 1e-100 ULP bracket is sufficient across a decade crossing; `neighbor` handles carries. extended vs extended2 mirror: diff regenerated (2,246 lines), each production function read in both; width parameters, deliberate commented collapse to U256 plus sticky, identical logic in add, mul, round helpers incl. carry, `div_u32`, `trunc_to_i32`, the predicate; defects documentation only (A3-8) plus the shared seed defect (A3-1). `parse_str` reachability: every production call passes a literal; `Extended2::parse_str` is `pub(crate)`.

## Design notes
1. A rung aware mirror filter would make "threshold below resolution" a construction time panic (A3-2).
2. `recip`/`sqrt` should own range and precision: rescale internally and derive step counts from `F::PRECISION`, closing P1B-2, A3-1 and fd-k9t at one site.
3. Budget units as a type (`Units` built only through `rel_to_units` and `half_ulp_of`) would have made the k·ln10 slip unwriteable.
4. Tier 2 printed from the catalog by a test (4·B₂·10^-(W−P)·N per function).
5. A table driven anchor classifier would make seam omissions visible (the atan2 lead).
