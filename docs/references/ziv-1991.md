# Ziv 1991 (adaptive precision; rejected for the fixed formats)

Ziv's rounding test loop is the classical route to correctly rounded
elementary functions and the road not taken for Decimal32/64/128:
ADR-0032 chose the Lefèvre and Muller fixed precision envelope
precisely because a provable worst case beats an expected case
fast path on embedded targets and under a verification-first posture.
The idea still earns a bounded appearance in `ferrodec-decimal`'s
correctly rounded transcendentals (ADR-0040), where working precision
is caller chosen and a capped retry ladder is the natural shape.
