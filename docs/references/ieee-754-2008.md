# IEEE Std 754-2008

The 2008 revision merged binary and decimal floating point into one
standard and introduced the two decimal interchange encodings, BID
and DPD, whose §3.5.2 declet tables the `dpd` feature implements and
the dqEncode and dqCanonical vectors exercise. ferrodec cites it only
for that lineage; every live clause reference resolves against
754-2019.
