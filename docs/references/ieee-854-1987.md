# IEEE Std 854-1987

The withdrawn radix-independent standard is cited for one structural
reason: the General Decimal Arithmetic model descends from it, not
from 754. GDA's context with an arbitrary working precision and
exponent range is an 854 inheritance, and the places where ferrodec's
754 storage formats cannot reproduce decNumber behavior (pre-clamped
operands, the BID structural CLAMPED residual) all trace to that
ancestry. The decimal-thread history entry tells the longer story.
